# Formation Bac — Guide HTML imprimable

Guide de révision express pour le baccalauréat **spécialité Mathématiques** et **spécialité Physique-Chimie**, adapté au profil cognitif du candidat (bilan neuropsychologique).

## Utilisation

1. Ouvrir `index.html` dans un navigateur (Chrome ou Firefox recommandé).
2. Attendre le chargement des formules (MathJax).
3. **Imprimer en PDF** : `Ctrl+P` → « Enregistrer au format PDF » → cocher **Graphiques d'arrière-plan**.

## Contenu

- Probabilités, géométrie dans l'espace, fonctions, suites (maths)
- pH, titrages, mécanique, synthèse organique, ondes, RC, cinétique, Bernoulli (PC)
- Plan sur 4 jours, fiches formules, checklist jour J
- Schémas SVG intégrés, formules MathJax

## Dépendances en ligne

- MathJax 3 (CDN jsDelivr) pour les symboles mathématiques et chimiques

Le fichier est autonome hors connexion une fois MathJax chargé ; pour l'impression PDF, une connexion internet est nécessaire au premier chargement.
