# Formation Bac — Guide HTML imprimable

Guide de formation **autonome** pour le baccalauréat **spécialité Mathématiques** et **spécialité Physique-Chimie**, adapté au profil cognitif du candidat (bilan neuropsychologique).

Chaque chapitre explique la logique derrière les formules (pas seulement les lister) : idée clé, schéma, pourquoi ça marche, recette, exemple guidé complet, pièges.

## Utilisation

En ligne : [yehielscourses.github.io/mathpc](https://yehielscourses.github.io/mathpc/)

En local (sans internet après la première ouverture) :

1. Ouvrir `index.html` dans un navigateur (Chrome ou Firefox recommandé).
2. Attendre le rendu des formules (MathJax inclus dans `vendor/`).
3. **Imprimer en PDF** : `Ctrl+P` → « Enregistrer au format PDF » → cocher **Graphiques d'arrière-plan**.

## Contenu

- **§0** — Comment lire le guide sans internet
- Probabilités, géométrie dans l'espace, fonctions, suites (maths)
- pH, titrages, mécanique, synthèse organique, ondes, RC, cinétique, Bernoulli (PC)
- Plan sur 4 jours, fiches formules, checklist jour J
- Schémas SVG intégrés, formules MathJax, encadrés « Comprendre » / « Pourquoi »

## Dépendances

- **MathJax 3** : inclus localement dans `vendor/tex-chtml.js` (pas de CDN requis pour l'impression hors ligne).
