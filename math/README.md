# Annales Bac — Spécialité Mathématiques (2021–2025)

Sujets et corrigés des épreuves de spécialité mathématiques du baccalauréat général, sessions 2021 à 2025.

## Organisation

```
math/
```

## Source

Documents téléchargés depuis [APMEP — Annales Terminale Générale](https://www.apmep.fr/Annales-Terminale-Generale).

Pour relancer le téléchargement : `python3 scripts/download_annales.py`
