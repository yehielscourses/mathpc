# Annales Bac — Spécialité Physique-Chimie (2021–2025)

Sujets et corrigés des épreuves de spécialité physique-chimie du baccalauréat général, sessions 2021 à 2025.

## Organisation

```
physique-chimie/
  2021/
    sujets/    — sujets officiels
    corriges/  — corrigés (lorsque disponibles)
  2022/
  ...
```

## Source

Documents téléchargés depuis [sujetdebac.fr](https://www.sujetdebac.fr/annales/specialites/spe-physique-chimie/).

Tous les sujets sont présents ; certains corrigés ne sont pas encore publiés en ligne pour toutes les sessions.

Pour relancer le téléchargement : `python3 scripts/download_annales.py`
